# Tazkora

### A Modern Desktop Task Management Application

Tazkora is a modern task management application built using Java Swing. It helps users organize their daily activities through a clean interface, task priorities, deadlines, and customizable themes.

## Features

- **Dashboard** – Overview of total, completed, and pending tasks.
- **Task Management** – Add, view, complete, and delete tasks.
- **Deadlines** – Assign due dates to tasks.
- **Priority Levels** – Organize tasks by Low, Medium, and High priority.
- **Search** – Find tasks quickly.
- **Customizable Themes** – Dark, Light, and High Contrast modes.
- **Modern UI** – A visually appealing desktop interface with notifications.

## Technologies Used

- Java
- Java Swing
- AWT
- Java Time API

## Getting Started

### Prerequisites

- Java Development Kit (JDK 17 or later recommended)
- Any Java-compatible IDE, such as Visual Studio Code

### Installation

1. Clone or download this repository.
2. Open the project folder.
3. Compile the application:

   ```bash
   javac MainGUI.java
   ```

4. Run the application:

   ```bash
   java MainGUI
   ```
